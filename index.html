1. Leading Zero Rule in MASM / emu8086

Hex values starting with A–F must have a leading 0 (e.g., 0Ah, 0Dh, 0FFh) so the assembler doesn't confuse them with labels or registers like AH or DH. In DOSBox debug, everything is already base-16 so write raw hex (0A, 0D, FF) without h.

2. CR (0Dh) vs. LF (0Ah) Cursor Trap

0Dh (Carriage Return) moves the cursor to column 0 of the same line (overwriting text if no LF!). 0Ah (Line Feed) moves the cursor down 1 row in the same column. You need both 0Dh, 0Ah for a full new line! Also, INT 21h / AH=01h returns 0Dh in AL when Enter is pressed.

3. Case & Digit Conversion Tricks

Digit ⇄ ASCII: '0'–'9' is 30h–39h (48–57). Add 30h (or OR AL, 30h) to convert a number 0–9 to ASCII; subtract 30h (or AND AL, 0Fh) for ASCII to number.
Upper ⇄ Lower: 'A'=41h (65), 'a'=61h (97). Difference is 20h (32): ADD/OR AL, 20h → lowercase; SUB AL, 20h / AND AL, 0DFh → uppercase.

4. String Terminators: '$' (24h) vs NUL (00h)

DOS INT 21h / AH=09h prints until it hits '$' (24h / 36). If you forget '$', it prints garbage from memory! Null-terminated strings use 00h instead.
