8. Loop strings in emu8086

Activity — Loop

A program that prints "I LOVE CCIS" five times.

Activity Source Code (LOOP.asm)

.MODEL SMALL            ; define memory model, allows one code and data segment
.STACK 100H
.DATA 
    MSG DB 'I LOVE CCIS', 0DH, 0AH, '$' ;0DH - CARRIAGE RETURN, 0AH - LINE FEED
    

.CODE 
    MAIN PROC           ; indicate beginning
        MOV AX, @DATA   ; LOAD THE ADDRESS OF DATA SEGMENT 
        MOV DS, AX    
        MOV CX, 5       ; CX, GENERAL PUPOSE REGISTER FOR LOOP COUNTER - 5 TIMES
    DISPLAY:
        MOV AH, 09H
        LEA DX, MSG     ; LOAD EFFECTIVE ADDRESS
        INT 21H
        LOOP DISPLAY
        MOV AH, 4CH     ; DOS FUNCTION TERMINATES PROGRAM
        INT 21H         ; INTERRUPT

MAIN ENDP
END MAIN     

; .ASM <- ACTIVITY 7

Output:
I LOVE CCIS
I LOVE CCIS
I LOVE CCIS
I LOVE CCIS
I LOVE CCIS

Logic

1. Memory & Data Setup

  • .MODEL SMALL: Sets the memory layout to allow one 64 KB segment for code and one 64 KB segment for data.
  • .STACK 100H: Reserves 256 bytes (100H in hexadecimal) of memory for the program stack.
  • .DATA: Marks the beginning of the data segment where variables are stored.
  • MSG DB 'I LOVE CCIS', 0DH, 0AH, '$': Defines a byte array (DB = Define Byte) named MSG containing:
    • 'I LOVE CCIS': The characters to display.
    • 0DH (13 in decimal): ASCII Carriage Return (\r), moving the cursor to the start of the line.
    • 0AH (10 in decimal): ASCII Line Feed (\n), moving the cursor down to the next line.
    • '$': The required string terminator for DOS print function 09H so DOS knows where to stop reading memory.

2. Initialization

  • .CODE & MAIN PROC: Marks the start of executable instructions and defines the MAIN procedure.
  • MOV AX, @DATA / MOV DS, AX: Loads the starting memory address of your .DATA segment into the Data Segment register (DS). Because x86 assembly does not allow moving a memory address directly into DS, it routes through the general-purpose AX register first.
  • MOV CX, 5: Sets the Counter register (CX) to 5. The LOOP instruction automatically uses CX to track how many iterations remain.

3. The Print Loop

  • DISPLAY:: A label marking the start of the loop block.
  • MOV AH, 09H: Selects DOS function 09H (Display String), which expects a $-terminated string address in DX.
  • LEA DX, MSG: Loads the Effective Address (memory offset) of MSG into DX so DOS knows where the string starts.
  • INT 21H: Triggers DOS interrupt 21H, executing function 09H to print "I LOVE CCIS" followed by a newline.
  • LOOP DISPLAY: Decrements CX by 1 (CX = CX - 1). If CX is not zero, it jumps back to the DISPLAY label; once CX reaches 0, execution continues to the next line.

4. Program Termination

  • MOV AH, 4CH / INT 21H: Calls DOS function 4CH (Terminate Program) via interrupt 21H to safely close the program and return control to the operating system.
  • MAIN ENDP / END MAIN: Closes the MAIN procedure and tells the assembler that MAIN is the entry point of the program.
