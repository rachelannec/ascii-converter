4. Writing .ASM in Text Editor & Compiling with TASM / TLINK

TASM & TLINK Workflow

Standard MASM/TASM assembly structure for displaying a single character, plus the DOSBox commands to assemble (tasm) into an object file (.obj) and link (tlink) into an executable (.exe).

Source Code (text5.asm)

Title this program will display a single character
dosseg
.model small
.stack 0100H
.code
    mov ah, 2       ; write char to standard output
    mov dl, 41H     ; HEX value of char 'A'
    int 21H         ; DOS function

    mov ah, 4ch     ; exit - terminate with return code
    int 21H
    int 20H
end

Directives & TASM / TLINK Commands

Directive / Step Explanation
dosseg Orders segments according to standard DOS convention (Code, Data, Stack).
.model small Uses the small memory model (one code segment ≤ 64KB, one data segment ≤ 64KB).
.stack 0100H Reserves 100h (256 bytes) for the stack.
mov ah, 4ch / int 21H Standard DOS termination for .exe programs (returns control to DOS).
Step 1: tasm text5.asm Translates assembly source into machine code object file (text5.obj).
Step 2: dir text5.* Verifies that text5.obj and text5.asm exist.
Step 3: tlink text5.obj Turbo Linker creates the executable text5.exe (and .map file).
Step 4: text5.exe (or text5) Runs the executable in DOSBox and outputs A.
