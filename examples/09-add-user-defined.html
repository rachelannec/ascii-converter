9. Add 3 digits and display the sum.

Activity — User-Defined

This program asks for three single-digit numbers, adds them together, and displays the two-digit sum.

Activity Source Code (ADD3.asm)

.model small
.stack 100h

.data 
    num1 db 0dh, 0ah, 'Enter 1st number: $'
    num2 db 0dh, 0ah, 'Enter 2nd number: $' 
    num3 db 0dh, 0ah, 'Enter 3rd number: $'
    sum db 0dh, 0ah, 'Sum: $`\'
    
.code
main proc
    mov ax, @data
    mov ds, ax
        
    ; -- 1st number
    mov ah, 09h
    lea dx, num1
    int 21h
    
    mov ah, 01h
    int 21h
    sub al, 30h     ;convert ascii to actual number 
    mov ah, 0h      ;clear ah so ax hold input number
    mov bx, ax      ;move ax to bx - 1st num
    
    ; -- 2nd number
    mov ah, 09h
    lea dx, num2
    int 21h
    
    mov ah, 01h
    int 21h
    sub al, 30h
    mov ah, 0h  
    mov cx, ax   ; move ax to cx - 2nd num
    
    ; -- 3rd number
    mov ah, 09h
    lea dx, num3
    int 21h
    
    mov ah, 01h
    int 21h
    sub al, 30h
    mov ah, 0h      ; clear ah so ax hold input number, ax - 3rd

    add ax, bx      ; add ax (3rd num) and bx (1st sum) -> result is ax
    add cx, ax      ; add cx (2nd num) and ax -> resutl in cx
    ; FINAL RESULT IN cx 
    
    ; -- print Sum:
    mov ah, 09h
    lea dx, sum
    int 21h
    
    ; -- split (for 2digit sum)
    mov ax, cx      ; move cx to ax
    aam
    add ax, 3030h
    mov bx, ax
    
    mov ah, 2h
    mov dl, bh
    int 21h
    mov dl, bl
    int 21h    
    
    
    ; exit
    mov ah, 4ch
    int 21h

main endp
end main

Logic

1. Setup & Text (.model, .stack, .data)

  • Sets up memory and stores the prompt messages (num1, num2, num3, sum). 0dh, 0ah creates a new line, and $ marks the end of each text string.

2. Load Data (mov ax, @data / mov ds, ax)

  • Connects the .data section so the program can access your text prompts.

3. Get 1st Number (saved in bx)

  • Prints "Enter 1st number: ", reads one keystroke (int 21h), subtracts 30h to turn the typed character into a real number, and stores it in bx.

4. Get 2nd Number (saved in cx)

  • Prints "Enter 2nd number: ", reads the second keystroke, converts it to a real number, and stores it in cx.

5. Get 3rd Number & Add Everything (ax, bx, cx)

  • Prints "Enter 3rd number: ", reads the third keystroke into ax, then adds all three numbers together (ax + bx, then + cx), leaving the final total in cx.

6. Split & Print the 2-Digit Sum (aam)

  • Prints "Sum: ", moves the total into ax, and uses aam to split it into tens (ah) and ones (al). It adds 3030h to turn both digits back into printable characters and prints them one by one (bh, then bl).

7. Exit (mov ah, 4ch)

  • Safely closes the program and returns to DOS.
