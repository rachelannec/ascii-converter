3. Vertical String Printing with Line Feed (ANNE.com → "BSCS3-3")

Activity — DOSBox Script

Displays BSCS3-3 vertically/diagonally by alternating each character with mov dx, a (0Ah = Line Feed). Notice AH stays 02 throughout, so only DX needs to change before each int 21.

Activity Script (ANNE.com)

a 100
mov ah, 02
mov dx, 42
int 21
mov dx, a
int 21
mov dx, 53
int 21
mov dx, a
int 21
mov dx, 43
int 21
mov dx, a
int 21
mov dx, 53
int 21
mov dx, a
int 21
mov dx, 33
int 21
mov dx, a
int 21
mov dx, 2d
int 21
mov dx, a
int 21
mov dx, 33
int 21
int 20

rcx
100
n ANNE.com
w
q

Hex-to-ASCII Breakdown

Instruction Hex ASCII Character
mov dx, 42 42h (66) 'B'
mov dx, a 0Ah (10) [LF] Line Feed (moves cursor down 1 line)
mov dx, 53 53h (83) 'S'
mov dx, 43 43h (67) 'C'
mov dx, 53 53h (83) 'S'
mov dx, 33 33h (51) '3'
mov dx, 2d 2Dh (45) '-' (Hyphen / Minus)
mov dx, 33 33h (51) '3'

Exam Tip: Because only 0Ah (LF) is printed between letters without 0Dh (CR), the cursor moves down 1 row after each character! To align strictly to column 0, pair 0Dh (CR) with 0Ah (LF).
