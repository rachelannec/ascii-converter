5. Displaying Multiple Strings with .data & AH=09h ("I love" / "CCIS")

Activity — String Output

Defines two '$'-terminated strings in the .data segment and prints them on separate lines using DOS function 09h and 10, 13 (LF + CR in decimal).

Activity Source Code (file.asm)

TITLE
.model small
.stack 0100H
.data 
string1 db 'I love', '$'
string2 db 10, 13, 'CCIS', '$'
.code
mov ax, @data
mov ds, ax
lea dx, string1
mov ah, 9
int 21H
lea dx, string2
mov ah, 9
int 21H
mov ah, 4ch
int 21H
int 20H
end

Output:
I love
CCIS

Key Instructions Explained

Instruction Meaning
string1 db 'I love', '$' Declares a byte array ending with '$' (24h), required by INT 21h / AH=09h.
string2 db 10, 13, 'CCIS', '$' Prepends decimal 10 (0Ah Line Feed) and 13 (0Dh Carriage Return) so CCIS prints at the start of the next line.
mov ax, @data
mov ds, ax		 Initializes the Data Segment register (DS) with the address of .data. (Cannot move an immediate address directly into DS!)
lea dx, string1 Load Effective Address: puts the offset address of string1 into DX.
mov ah, 9
int 21H		 Calls DOS function 09h to display the string at DS:DX until '$' is reached.
