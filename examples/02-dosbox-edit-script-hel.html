2. Using DOSBox edit & Input Redirection (HEL.com / text2.com)

DOSBox Editor + debug < file.asm

Instead of typing line-by-line inside debug, write the debug commands in DOSBox edit (blue screen), save as .asm or .txt, and feed it into debug using debug < filename.asm.

Activity Script (HEL.com)

a 100
mov ah, 02
mov dx, 41
int 21
int 20

rcx
100
n HEL.com
w
q

Output when running HEL: A (since 41h = ASCII 'A')

Line-by-Line & Workflow Explanation

Line / Command Meaning
a 100 Start assembling at memory address 100h.
mov ah, 02 DOS function 02h: display a single character.
mov dx, 41 Loads 0041h into DX (sets DL = 41h, which is uppercase 'A').
int 21 / int 20 Execute DOS interrupt 21h, then terminate with 20h.
[Blank Line] Important: Blank line (Enter with whitespace) exits a 100 assemble mode back to the - prompt!
rcx → 100 Sets register CX = 0100h (256 bytes) for file size.
n HEL.com / w / q Sets file name to HEL.com, writes file to disk, and quits.
dir / type file.asm Checks that the file is saved and displays its text contents.
debug < file.asm Feeds the script into debug to generate HEL.com, then type HEL to see the output.
