7. Add and subtract Using emu8086

Activity — Using emu8086

The program add and subtract two values and display the sum at cx while the difference at dx.

Activity Source Code (ADSUB.asm)

mov ax, 5h ;move 5 to ax
mov bx, 3h ;move 3 to bx
           
mov cx, ax ;move ax (5) to cx
add cx, bx ;add cx (5) to bx (3)
           ;result will be on cx <-8

mov dx, ax ;move ax (5) to dx
sub dx, bx ;subtract dx (5) to bx (3)
           ;result will be on dx <- 2

Logic

The program adds the value in ax to the value in bx and stores the result in cx, by first putting the value of ax to cx.

Same with subtraction, put first the value of ax to dx, then subtract it to the value of bx, the difference will then be stored in dx.
