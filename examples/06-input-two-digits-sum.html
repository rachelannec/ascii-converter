6. User Input & Single-Digit Addition ("The sum is $")

Activity — Input & Arithmetic

Clears the screen with BIOS INT 10h, reads two single-digit numbers from the keyboard using INT 21h / AH=01h, adds them, subtracts 48 (30h) to fix the ASCII offset, and displays the sum.

Activity Source Code

TITLE
.model small
.stack 0100H
.data
string1 db 10,13, 'Enter first number: $'
string2 db 10,13, 'Enter second number: $'
string3 db 10,13, 'The sum is $'
.code
mov ax, 03h
int 10h
mov ax, @data
mov ds, ax
lea dx, string1
mov ah, 09
int 21h
mov ah, 1
int 21h
mov bl, al
lea dx, string2
mov ah, 09
int 21h
mov ah, 1
int 21h
mov bh, al
add bl, bh
sub bl, 48
lea dx, string3
mov ah, 09
int 21h
mov ah, 02
mov dl, bl
int 21h
mov ah, 4ch
int 21h
end

Step-by-Step Logic & ASCII Math

Instruction Meaning
mov ax, 03h
int 10h		 Sets BIOS video mode 03h (80×25 16-color text), which clears the screen.
mov ah, 1
int 21h		 Reads a single character from keyboard with echo; stores its ASCII code in AL.
mov bl, al / mov bh, al Saves the first input character in BL and the second in BH so future INT 21h calls don't overwrite them.
add bl, bh
sub bl, 48		 Why subtract 48 (30h)?
Suppose you type '2' (ASCII 50) and '3' (ASCII 51):
50 + 51 = 101.
Subtracting 48 ('0') gives 101 - 48 = 53, which is the exact ASCII code for '5'!
mov ah, 02
mov dl, bl
int 21h		 Moves the resulting ASCII sum from BL into DL and prints it to the screen.
