1. Running a Program Directly in DOSBox debug (file.com)

DOSBox Command Prompt

Type commands directly inside DOSBox debug to assemble instructions into memory starting at offset 0100h, calculate byte size using h, and save as a .com executable.

Code / Commands Typed in debug

-a
072A:0100 mov ah, 02
072A:0102 mov dl, 61
072A:0104 int 21
072A:0106 int 20
072A:0108 [Press Enter]
-h 0108 0100
0208  0008
-r cx
CX 0000 :8
-n file.com
-w
Writing 0008 bytes
-q

C:\>file
a

Line-by-Line Explanation

Command / Instruction Meaning
a Starts Assemble mode at default offset 0100h.
mov ah, 02 Selects DOS function 02h (display single character on screen).
mov dl, 61 Loads hex 61h (ASCII for lowercase 'a') into DL.
int 21 Calls DOS Interrupt 21h to execute function 02h.
int 20 Calls Interrupt 20h to terminate the .com program.
h 0108 0100 Calculates hex sum (0208) and difference (0008) between end address 0108 and start address 0100.
r cx → 8 Views/modifies CX register and sets file size to 8 bytes.
n file.com Names the output file file.com.
w / q Writes (saves) the 8 bytes to disk, then quits debug.
